### Genspark Sol 5.6 (via OpenCode + Genspark LLM proxy)
Do **not** use `genspark task create super_agent`, because it does not guarantee
model selection.

Setup, once per session:
```bash
gsk_cfg_dir=$(mktemp -d)
genspark init-opencode -o "$gsk_cfg_dir/opencode.json" >/dev/null
```
Each run:
```bash
gsk_run_data=$(mktemp -d)
XDG_DATA_HOME="$gsk_run_data/data" XDG_STATE_HOME="$gsk_run_data/state" \
OPENCODE_CONFIG_CONTENT="$(jq -c 'del(.genspark)' "$gsk_cfg_dir/opencode.json")" \
opencode run --model genspark-llm-proxy/gpt-5.6-sol --agent plan \
  --dir /Users/stevencommander/Desktop/AI/op-patchstudio-improved 'READ-ONLY TASK'
```
- 🔒 The generated `opencode.json` **contains an API key. NEVER print, cat,
  echo, log, or share it.**
- `del(.genspark)` is required because stock OpenCode rejects the extra key.
- Fresh XDG dirs per run avoid a local SQLite `replacement_seq` schema mismatch.
