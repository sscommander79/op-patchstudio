    ⇧

    Move a device preset

    The working app would create a device preset ZIP. The transfer itself is guided: extract the ZIP, copy its .preset folder, then check it on the instrument.

    1. Download the device preset ZIPChoose a finished sound in the working app and export its device preset.
    2. Extract the ZIPKeep patch.json and audio files together inside the named .preset folder.
    3. Connect OP-XY in MTP modeOn macOS, open the device storage with the transfer tool described in the device guide.
    4. Copy the .preset folder to presetsPlace the extracted folder in the device’s presets location; do not copy the ZIP itself.
    5. Eject and check on the deviceLoad the preset and listen across its pads or keyboard zones.

    Direct browser USB upload: future investigation, not a working feature. This prototype does not connect to a device.

    ALWAYS HERE WHEN YOU NEED IT

    Help with your next step

    Search a task or open a guide. These are proposed explanations, not live device instructions.

    Sample one synth sound

    Bring audio from a hardware synth or a DAW into a browser-selectable input. You can play a note or phrase yourself. MIDI is optional for this one-sound path.

    Multisample several notes

    Automatic capture needs two routes: MIDI note triggering to the synth, and audio returning from the synth to an input the browser can capture. Review each note and mapping before saving.

    Use a software synth

    Open the instrument in your DAW. A browser page does not host a VST. Route DAW audio through a supported loopback or interface input; add a MIDI route only if automatic notes are needed.

    Use a hardware synth

    Connect synth audio to your interface and choose that input in the working app. For multisampling, also route computer MIDI output to the synth and confirm the channel and note response.

    Build a drum kit

    Start from separate one-shots, record new hits, or slice a longer recording. Assign sounds to pads, review each pad, and save the editable kit before device export.

    Back up and restore

    The proposed full backup should include audio, settings, tags, favorites, and collection membership. Restore should preview changes and ask how to handle duplicates.

    Transfer to OP-XY

    Download a device preset ZIP, extract it, copy the intact .preset folder to the device’s presets folder in MTP mode, then eject and check the sound on OP-XY. Browser USB upload is not available.
