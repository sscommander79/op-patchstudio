## Coordinator disposition after review

- The cross-tab guard gap is now covered by real IndexedDB tests: unchanged/changed revision detection, rejection of stale saves, explicit restore adoption, and the actual window-focus warning with an out-of-band competing write. The stale tab retains its unsaved edit; a pagehide flush cannot replace the newer stored version. Retry is intentionally absent for revision conflicts.
- Saved-to-library flag tests verify both flag transitions advance the revision, stale flag writes are rejected without changing storage, and the instrument name survives. The review missed existing clear/reset confirmation coverage in instrument-utility-audit.spec.ts; the direct storage test adds stronger evidence.
- All five storage cases pass on Chromium, Firefox, WebKit, Mobile Chrome and Mobile Safari: **25 passed**. New test managers are disposed in finally blocks.
- Production capture/download functions have the cited browser workflow coverage. Browser hits are not merged into the unit coverage percentage.
- Every B classification is retained as dormant/unreferenced code. Deleting these modules, restoring a historical size-warning feature, or changing unrelated tests is not necessary for this repair. No execution or correctness claim is made for retained dormant code.
- The review does not justify a literal every-function guarantee. Function coverage remains 72.95% in the unit suite, with browser workflows providing additional separate evidence.
